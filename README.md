# Mały matematyk – Android MVP

Bezpłatna aplikacja treningowa dla uczniów klas 1–8. Wersja demonstracyjna zawiera wybór klasy, działy treningowe, pytania wielokrotnego wyboru, podpowiedzi, wyjaśnienia i lokalny zapis punktów.

## Budowanie APK bez Android Studio

Projekt zawiera GitHub Actions. Instrukcja krok po kroku znajduje się w `GITHUB-INSTRUKCJA.txt`. Po przesłaniu projektu do repozytorium GitHub workflow zbuduje testowy plik APK i udostępni go jako artifact.

## Ważne ograniczenia MVP

- Zadania w aplikacji są przykładowe i autorskie; nie są oficjalnymi arkuszami konkursów.
- Punkty są zapisywane lokalnie na urządzeniu.
- Nie ma jeszcze kont uczniów, synchronizacji online ani produkcyjnego panelu administratora.
- To wersja testowa, niegotowa do publikacji w Google Play.
